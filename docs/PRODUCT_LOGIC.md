# MineM 产品逻辑总览

版本：0.5.0-alpha.31 · 2026-08-02

本文是 MineM 当前产品对象、核心链路和跨模块规则的总索引。细节需求以
`MineM_PRD.md` 为准，工程实现以 `MineM_TECHNICAL.md` 为准；两者与本文冲突时，
必须先修正文档再修改代码。

## 1. 产品定位与边界

MineM 是本地优先的汇报素材工作台，用于导入、整理、预览、编排、复用和导出汇报、
页面、案例与资源素材。平台管理素材和引用关系，不替代生成素材的 AI、CLI 或页面
生成 Skill。

边界规则：

- 源码、模板、文档与可复现配置进入 Git；数据库、客户素材、导入副本、缩略图和导出
  产物只存在于运行数据目录。
- 平台前端、CLI、macOS 客户端均通过同一 HTTP API 操作素材，不直接修改 SQLite。
- 自动扫描默认关闭；只有用户显式导入或配置来源后才处理外部文件。
- 知识图谱已经删除，不保留入口、接口、任务或自动生成逻辑。来源追溯由原数据链路承担。
- AI 演讲台、语音模型和演讲稿属于可选辅助能力，不进入汇报 HTML 导出包。

## 2. 核心对象

### 2.1 汇报素材

- 外部编号：`RPT-*`
- 数据类型：`asset_type=report`
- 语义：一份多页完整汇报，是页面引用和资源关系的聚合根节点。
- 汇报自身保存标题、来源、版本、活动时间和公开入口；页面顺序以已确认页槽与编排为准。
- 删除汇报只删除汇报自身及专属关系，不删除其引用的页面素材和资源素材。

### 2.2 页面素材

- 外部编号：`CTRL-*`
- 数据类型：`asset_type=control`
- 语义：恰好一页、可独立预览和复用的页面。
- 多页输入不能作为一个页面素材发布；必须先识别为汇报或案例，再拆出逐页页面素材。
- 页面被插入、替换或移出汇报时，只变更页槽引用，不复制或删除页面本体。

### 2.3 案例素材

- 外部编号：`CASE-*`
- 语义：由同一外部文档提炼出的案例组和多张案例页面。
- 案例可以多页，但不是汇报素材；案例页面可以作为页面素材插入汇报。
- 案例列表读取真实案例与页面关系，不使用前端静态示例数据。

### 2.4 资源素材

- 外部编号：`RES-*`
- 数据类型：`asset_type=resource`
- 语义：图片、Logo、图标、GIF、视频、SVG 等页面依赖。
- 相同内容按内容指纹复用；重复导入可以形成版本或引用关系，不能制造并列重复卡片。
- 合并资源不得改写已有页面的可用路径；任何引用迁移必须先验证全部页面仍可渲染。

### 2.5 故事线

- 外部编号：`STL-*`
- 语义：汇报结构和来源汇报的收藏记录。
- 收藏新故事线只新增故事线，不新增汇报。
- 更新已有故事线会新增故事线版本，旧版本永久保留；故事线详情展示全部版本和原始汇报。

## 3. 核心工作流

### 3.1 外部导入

统一状态机：

`received -> extracted -> normalized -> validated -> classified -> published -> preview-ready`

1. 接收 HTML、ZIP、PDF、MD 或受支持媒体，写入任务暂存区。
2. 安全解压并规范化临时运行时引用，不从历史批次借用同名文件。
3. 递归校验 HTML、CSS、iframe、图片、视频、字体等本地依赖闭包。
4. 识别内容对象：多页汇报、案例组、单页页面或资源；单页与多页不得混类。
5. 在真实浏览器中验证尺寸、关键内容和可渲染性。
6. 在单个短事务中发布素材、逐页页面、页槽和资源关系。
7. 事务提交后异步生成缩略图；缩略图失败不能污染正式关系，但任务不得误报预览成功。

失败规则：

- 任一正式页面缺失、依赖缺失或分类不确定时，整批不发布。
- 相同内容重试使用规范化包指纹保持幂等，不重复生成汇报、页面或资源卡片。
- 服务重启后遗留的运行中任务标记为可重试失败，不自动继续写库。

### 3.2 创建与复用汇报

- 新建汇报时按用户顺序引用已有页面素材；页面素材本体不复制。
- 从零生成的新页面先成为独立页面素材，再创建汇报页槽引用。
- 替换页面只替换目标页槽；原页面版本和其他汇报引用保持不变。
- 所有生成或编辑成功的素材更新业务活动时间，并进入对应列表顶部。

### 3.3 汇报编排

- 拖拽、隐藏、恢复、插入和移出先保存在当前前端会话。
- 关闭有未确认修改的编排页时，提示保存、放弃或继续编辑。
- 点击“确认编排”后，服务端在单一事务中重排页槽、写入隐藏集合并更新时间。
- 前端保持“正在生效”状态，直到服务端回读结果与提交序列一致后才提示成功。
- 隐藏或移出只影响当前汇报，不删除页面素材；汇报至少保留一个可用页面。
- 汇报播放、详情预览、公开链接和导出只读取已确认编排。

### 3.4 预览与尺寸

- 平台查看壳的目标画布统一为 1920×1080、16:9；来源内容在壳内等比适配。
- 新导入内容保留原始页面尺寸元数据，但管理列表和汇报查看器不能出现二次缩放或嵌套导航。
- 汇报只保留平台统一页码胶囊、键盘翻页和全屏逻辑；来源页面自身导航在嵌入态禁用。
- 卡片优先读取稳定缩略图；详情和打开链接才加载交互 iframe。
- iframe 仅在接近视口时挂载，离开远端视口时释放，避免列表一次加载大量页面。
- 预览缓存键包含素材更新时间；素材变化后旧缩略图失效并异步替换。
- 20 秒未完成只显示慢加载状态，不误报错误；404、素材缺失或真实加载错误才显示重试入口。

### 3.5 导出

- HTML 和 PDF 只导出当前已确认且可见的页面顺序。
- HTML 包递归收集当前页面实际依赖，保持图片、视频、GIF、字体等二进制原样，不设置 300MB
  硬限制，不复制无关导入目录。
- PDF 等待字体、图片、视频首帧和页面动效稳定后逐页截图；任一页失败则整批失败。
- 导出不包含语音模型、TTS、AI 演讲台、演讲稿或运行时诊断文件。

### 3.6 AI、CLI 与 macOS 客户端

- macOS 创作助手只提供汇报、页面、案例场景的短指令复制，不直接执行写库操作。
- 指令明确固定 Skill、待补充信息和目标结果；用户在 Codex 等 AI 对话中补充附件、链接或编号。
- AI 通过 `minem` CLI 调用平台 API 完成创建、插入、替换、修改和导入。
- CLI 发现当前服务端口与会话令牌，调用现有 API；禁止直接写 SQLite 或素材目录。

## 4. 全局交互规则

- 汇报、页面、案例、资源和故事线列表按最近业务活动时间倒序。
- 页面和资源的活动时间包含新增、编辑、生成新版本以及被汇报引用的时间。
- 素材列表默认每批 30 条，滚动加载下一批；筛选、搜索或切换模块后回到第一批。
- 搜索支持编号、名称、标签、来源路径和平台链接。
- 高频命令直接展示；低频命名、复制 ID、删除和诊断信息收纳到“更多”。
- 卡片只展示识别、判断和下一步操作所需字段；完整来源与批次字段进入详情。
- 加载、空数据、失败、慢预览、处理中和成功必须是不同状态，不用无限加载代替空状态。
- 所有图标按钮提供 `title` 或 `aria-label`；控件尺寸、圆角和间距遵循设计系统。

## 5. 数据一致性规则

- `RPT-*` 只能是汇报；`CTRL-*` 只能是一页页面；`CASE-*` 只能是案例；`RES-*` 只能是资源。
- 编号、类型、页面数量和来源以结构化字段为准，不能只根据标题或文件名推断。
- 汇报页槽必须引用存在的页面素材；页面资源关系必须引用存在且可访问的资源。
- 自动去重只处理高置信、语义与视觉均一致的页面；不确定项进入人工合并。
- 自动或人工合并保留来源记录、版本和引用链；列表只展示版本组主记录。
- 写接口使用会话令牌并保持幂等；失败导入不产生正式素材。
- 素材删除、合并、重建和迁移必须先检查反向引用，不能造成空白图片或失效链接。

## 6. 代码职责

### 前端

- `frontend/src/App.tsx`：页面路由与顶层状态协调，不承载领域算法。
- `frontend/src/productLogic.ts`：列表排序、编号解析、类型文案和创建指令等纯产品规则。
- `frontend/src/components/AssetPreview.tsx`：统一缩略图、媒体和 HTML 预览生命周期。
- `frontend/src/components/ImportWidgets.tsx`：导入对话框与任务状态。
- `frontend/src/components/CaseControlLibrary.tsx`：案例组与案例页面。
- `frontend/src/components/Workbench.tsx`：工作台摘要与入口。

### 后端

- `server.py`：HTTP 适配、路由与兼容入口；后续只保留薄控制层。
- `minem/imports.py` 与导入模块：导入状态机、校验、分类和发布。
- `minem/assets.py`：素材读取、展示数据和活动时间。
- `minem/reports.py`、`report_canvas.py`：汇报页槽、编排、公开入口和尺寸壳。
- `minem/thumbnails.py`：可再生缩略图任务与缓存失效。
- `minem/report_exports.py`：离线 HTML 与 PDF 导出。
- `minem/db.py`：连接、事务和迁移，不承载产品分类规则。

### 客户端与自动化

- `desktop/`：macOS WebView 客户端和创作助手。
- `scripts/minem_cli.py`：CLI API 客户端。
- `skills/minem-html-page/`：AI 创建并发布 HTML 页面素材的 Skill。

## 7. 后续重构顺序

1. 保持接口和行为不变，先拆分前端纯规则、预览、详情、编排和演讲台组件。
2. 为导入、编排、删除、合并、导出建立服务层契约测试。
3. 将 `server.py` 中已具备独立模块的路由逐批迁移为薄 Handler。
4. 最后处理数据库事务边界和历史兼容代码；每批迁移都先跑数据与预览回归。
5. 未通过现有测试、数据审计和真实浏览器预览的阶段不得继续删除兼容实现。
