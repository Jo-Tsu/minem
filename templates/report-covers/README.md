# Default report covers

These three geometric backgrounds were created for MineM using procedural gradients and curves. They contain no third-party logos, imported presentation content or business material. They are distributed under the repository Apache-2.0 license.

For personal templates, place `cover-1.webp`, `cover-2.webp` and/or `cover-3.webp` under `config/report-covers/` inside `MINEM_DATA_DIR`. Local overrides are never part of the public source repository. Existing report pages keep their packaged cover files.
